# Starship by Pranav Karthik

Space-themed React portfolio for milestone progress check-in.

## Milestone Requirement Checklist

- Code committed to GitHub repository
- Deployable to GitHub Pages using:
  - `npm run build`
  - `npm run deploy`
- Consistent design system usage with React Bootstrap
- Primary navigation bar is present and functional
- At least 3 routed pages:
  - `/` (Bridge / Home)
  - `/projects` (Mission Log)
  - `/about` (Crew)
- 8+ components are meaningfully used across the app
- Meaningfully interactable feature:
  - Interactive Mission Console on Projects page with live search, status filtering, and mission detail selection

## Short Demo Video Plan (2-4 minutes)

1. Open deployed site and quickly show global space-themed styling and navbar.
2. Navigate through all three main pages to show routing is functional.
3. On Projects page, demonstrate Mission Console:
   - type in search
   - switch status filter
   - click mission entries to view details
4. Briefly mention component structure and reusable Bootstrap UI patterns.
5. Close by summarizing progress made since previous milestone.
